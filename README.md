# AI-Based Security Monitoring System for Public Wi-Fi Networks

## Project Overview
This project aims to develop an AI-based network security monitoring prototype for identifying suspicious network traffic in public Wi-Fi environments.

## Main Objectives
- Analyse network traffic data.
- Identify normal and suspicious traffic using machine learning.
- Generate security alerts.
- Monitor network activity through a web-based interface.
- Present traffic analysis and detection results.

## Technologies
- Python
- Machine Learning
- Random Forest
- Flask
- HTML, CSS and JavaScript
- GitHub
